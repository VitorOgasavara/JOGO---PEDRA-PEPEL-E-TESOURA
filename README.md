# ✊✋✌️ Jogo Pedra, Papel e Tesoura

## 🎮 Sobre o projeto

Bem-vindo ao **Jogo Pedra, Papel e Tesoura**!

Este projeto apresenta uma versão digital do clássico jogo Pedra, Papel e Tesoura, desenvolvido para colocar em prática conhecimentos de programação, lógica e desenvolvimento de jogos.

O objetivo é simples: escolher uma das três opções e tentar vencer o adversário!

## 🕹️ Como jogar

O jogador deve escolher uma das opções:

- ✊ **Pedra**
- ✋ **Papel**
- ✌️ **Tesoura**

O resultado é definido pelas regras tradicionais do jogo.

### 📜 Regras

| Escolha | Vence de |
|---|---|
| ✊ Pedra | ✌️ Tesoura |
| ✋ Papel | ✊ Pedra |
| ✌️ Tesoura | ✋ Papel |

Se os dois jogadores escolherem a mesma opção, a rodada termina em **empate**.

## 🎯 Objetivo do projeto

Este projeto foi criado para praticar conceitos de programação, como:

- Estruturas condicionais
- Lógica de programação
- Comparação de resultados
- Organização de código
- Desenvolvimento de jogos simples

## 🚀 Como executar

1. Acesse o repositório no GitHub.
2. Baixe os arquivos ou clone o projeto.
3. Abra a pasta em seu editor de código.
4. Execute o projeto conforme a linguagem e os arquivos utilizados.
